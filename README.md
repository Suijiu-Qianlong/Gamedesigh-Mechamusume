## 架构注释（人物设计到现实落地全链条）
- 这个CS-001只是我拿来测试的通用机娘，实际上我要造的是我的六大机娘，这个主线剧情是为了通过意外事件体现机娘爽燃魅力，日常无意外事件只能展示一下机娘的搞笑萌啊，先拿六大机娘里的墨音机娘MY-103来说，我把诸葛亮的算无遗策、鞠躬尽瘁，知天易逆天难，内心不可知量子态，和灵境行者里的孙淼淼好奇宝宝，还有日漫那种呆萌属性，给她融成了一个角色，名场面是主角假死，墨音挺身而出之执剑，我们绝不屈服，让星海燃烧，让宇宙沸腾，现在回来看CS-001测试通用机娘，她的言语是天然呆软妹，38条一维线两极状态参数文本，语音是洛天依AI那种固定声色材质＋声轨训练材料，匹配文本自动生成符合人设语气的有感情语音，动作是预设多套限制力道安全第一的稳定动作模块，算法实时生成那种破玩意我才不用啊，只能拿来打乒乓球，服装是静态模式进行拆卸安装，定制体型服装随时可以换，搭载了理性算法拟合＋感性模拟行动，独立双模块，技术实现是云端算法调用＋嵌入式芯片RTOS实时系统，她的功能可以大数据检索验证和处理简单重复工作，然后用言语安抚你的情绪，夸奖、认同、支持你，那种插座服务我不搞，不要玷污我机娘的圣洁，做个人吧，规则是阿西莫夫几条定律改良版，不需要救人不伤害就行，她的模式是常态待机省电＋唤醒切换长时间询问指令模式，适用范围：唱歌、家庭陪伴、心理疏导、辅佐工作，这个暂时手游测试，那个现实机器人组装难度太大了，第二个页码是RTOS实时系统写入以及架构连接系统，我还没写啊，这个到时候再说吧，第三页是仿银河麒麟地面控制系统实时写入文本生成语音，这个可以用来在商业街大屏幕进行live2d直播演示，第四页是仿生身体构造和电池续航以及芯片系统定制，这个仿生身体主要分为外壳、关节、传感器三个部分，硅胶不好用，前沿的胶原蛋白基电子感觉仿真度比较高，那个锂原子电池就是仿天问二号的那个电池超长续航，第五页是特制安全保障系统和应急处理方案，防黑客自动关机，电磁干扰屏蔽，滤波，多传感器协同，应急方案就是那个着火了自动远离易燃物和人类，无害化处理，减少安全隐患，最后一页是成本预估，线上服务器运营，硬件测试，维护，还有伦理法律法规注意避免一下，此乃人类智慧集合结晶。
