## 游戏架构（unity/godot）
- 主模块（DialogueEngine）
-    ├── 加载并管理所有独立模块
-    ├── 接收玩家输入 → 多次路由最终状态 → 获取回应ID
-    ├── 根据回应ID查询内置文件夹数据库
-    └── 输出：文本 + Live2D表情 + Live2D动作 + 语音
- 内置文件夹数据库（ScriptableObject资产）
-    ├── 文本库：ID → 回应文本
-    ├── 表情库：ID → Live2D表情参数
-    ├── 动作库：ID → Live2D动作指令
-    ├── 语音库：ID → 语音片段
-    ├── 场景美术库：ID → 场景资源（关键输入切换，不进入终端输出）
-    └── UI美术库：ID → UI资源（系统模块内可启用/隐藏）

- res://

## 机娘设定集（原创）——《机娘时代1：光明命谱》
### 端游手游（预计上steam）
- 游戏逻辑架构采用CRSM-PARS（详见Mechamusume仓库），每名机娘至少含有10w条文本（包含变体）与玩家进行深度拟真互动
- 主要角色：灰风、冰凝、烬煌、墨音、绮梦、星湮
- 人设画风在我抖音号25048587714（岁久潜龙）、25048587714S（元序列），官设在pixic号20333396
### 人物设定和剧情梗概

- 六大机娘1：六个机娘摸头反应都不同，灰风被摸是嘿嘿傻笑，冰凝被摸是无语白眼，墨音被摸是脸红破防，烬煌被摸是哼原谅你了，绮梦被摸是你犯规我不服我要打你，星湮被摸是心安但商量语气让你拿开但不会打你
- 主角团命格：主角的命我为天命睥睨世间（定义者），灰风的命我是世界上最强的机娘我敢冲（悍勇者），冰凝的命是我命由我不由天（抗命者），墨音的命是知不可为而为之（穷算者），烬煌的命是家人不在天地无心（挚爱者），绮梦的命有我保护无需忍痛（牺牲者），星湮的命是我强大大家就不用怕（威慑者）
- 主角顾沉设计：定义者|你的胜利从未存在的装逼，我什么都不需要做你就会自爆的从容，天机推演洞察一切的智慧，永远藏着底牌的谨慎，我要创造光明森林的偏执，我能看色色但我想方设法让自己看不见的知行合一，我不敢再做因为我害怕失去的凄惨
